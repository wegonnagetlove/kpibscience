# Масштаб исследований кафедры

Сайт: https://wegonnagetlove.github.io/kpibscience/

Интерактивная шкала научных работ сотрудников кафедры компьютерного права и информационной безопасности Высшей школы государственного аудита (факультет) МГУ имени М.В. Ломоносова.

Навигация устроена по образцу шкал «масштаба вселенной»: колесо мыши, ползунок или жест пальцем плавно переводят от мелкого к крупному. Вместо физического размера используется масштаб объекта правового регулирования, которому посвящена работа:

| № | Уровень | Что относится |
|---|---|---|
| 1 | Данные | единица информации, персональные данные |
| 2 | Алгоритм | программа, модель искусственного интеллекта |
| 3 | Человек | субъект права, пользователь, обучающийся |
| 4 | Организация | оператор, университет, информационная система |
| 5 | Отрасль | рынок, финансовая система, цифровая экономика |
| 6 | Государство | национальная правовая система, информационная безопасность России |
| 7 | Международный уровень | международная информационная безопасность, юрисдикция |
| 8 | Глобальная среда | глобальное информационное пространство, метавселенная |

Отнесение работы к уровню является редакционной классификацией по заглавию и предмету и правится в файле данных.

## Структура

```
index.html          страница
assets/style.css    оформление (белый фон, Google Sans, палитра #4285F4 #EA4335 #FBBC04 #34A853)
assets/app.js       движок шкалы, фильтры, карточки, список
data/research.js    все данные: уровни, сотрудники, источники, работы
```

Сборка не нужна: это статический сайт без зависимостей. Для просмотра достаточно открыть `index.html` в браузере.

## Как добавить работу

Допишите объект в массив `WORKS` в `data/research.js`:

```js
{ id: "z-example", authors: ["zueva"], year: 2025, type: "article", level: 1,
  title: "Заглавие статьи",
  gost: "Зуева, А.С. Заглавие статьи / А.С. Зуева. — Текст : непосредственный // Название журнала. — 2025. — № 1. — С. 10-20.",
  source: "istinaZueva" }
```

Поля:

* `authors` идентификаторы из `PEOPLE`; соавторов не из кафедры пишите в `coauthors`;
* `type` одно из `article`, `book`, `thesis`, `talk`, `event`, `supervision`;
* `level` число от `-3` (Данные) до `4` (Глобальная среда);
* `gost` библиографическая запись по ГОСТ Р 7.0.100-2018;
* `source` ключ из `SOURCES`; у источника флаг `primary: true` ставится только для официального документа (сайт МГУ, ИСТИНА, выходные данные издания);
* `verify` необязательное замечание, если реквизиты неполны; в карточке оно выводится блоком «Требует сверки».

Новый сотрудник добавляется в `PEOPLE`, новый источник в `SOURCES`. Ссылка на конкретную работу: `адрес-сайта/#id-работы`.
