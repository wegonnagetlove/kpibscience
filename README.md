# Масштаб исследований кафедры

Сайт: https://wegonnagetlove.github.io/kpibscience/

Интерактивная шкала научных работ сотрудников кафедры компьютерного права и информационной безопасности Высшей школы государственного аудита (факультет) МГУ имени М.В. Ломоносова.

Карта устроена как вселенная: каждая работа звезда, каждый уровень масштаба созвездие. В центре кафедра, от неё по спиральному рукаву расходятся девять созвездий от самых малых объектов исследования к самым крупным. Карту можно перетаскивать и приближать колесом мыши или жестом; при приближении у звёзд появляются заглавия, нажатие открывает карточку работы.

| № | Уровень | Что относится |
|---|---|---|
| 1 | Данные | единица информации, персональные данные |
| 2 | Алгоритм | программа, модель искусственного интеллекта |
| 3 | Человек | субъект права, пользователь, обучающийся |
| 4 | Организация | оператор, университет, информационная система |
| 5 | Отрасль | рынок, финансовая система, цифровая экономика |
| 6 | Государство | национальная правовая система, информационная безопасность России |
| 7 | Международный уровень | международная информационная безопасность, юрисдикция |
| 8 | Глобальная среда | глобальное информационное пространство, интернет, метавселенная |
| 9 | Космос | космическая деятельность, космонавтика, история космической техники |

Уровень присваивается автоматически по ключевым словам заглавия (правила `RULES` в `build/build.py`); работы без признаков другого уровня попадают на уровень «Государство».

Сайт статический и без зависимостей: для просмотра достаточно открыть `index.html` в браузере.

## Структура

```
index.html          страница
assets/style.css    оформление в стиле выставочной страницы: Oswald, Cormorant Garamond, PT Serif, карта на фоне снимков с орбиты
assets/img/         фотографии фона карты (набор и подписи в data/research.js, PHOTOS)
assets/app.js       карта-вселенная на canvas, фильтры, карточки, список
data/research.js    настройки: уровни, сотрудники, источники, работы вне ИСТИНА
data/works.js       работы из ИСТИНА МГУ (генерируется, вручную не править)
build/build.py      сборка data/works.js из выгрузки
build/istina/       выгрузка ИСТИНА: списки работ по профилям, BibTeX каждой записи, найденные DOI
```

## Обновление из ИСТИНА

1. Выгрузить заново списки (`build/istina/<сотрудник>.txt`) и BibTeX (`bib.json`).
2. Запустить `python3 build/build.py`: скрипт пересоберёт `data/works.js`, библиографические записи по ГОСТ Р 7.0.100-2018 и уровни шкалы.

## Как добавить работу вне ИСТИНА

Допишите объект в массив `WORKS` в `data/research.js` (поля: `id`, `authors`, `year`, `type`, `level`, `title`, `gost`, `source`, необязательно `verify`). Работы из ИСТИНА добавляются только пересборкой.
