# Масштаб исследований кафедры

Сайт: https://wegonnagetlove.github.io/kpibscience/

Интерактивная шкала научных работ сотрудников кафедры компьютерного права и информационной безопасности Высшей школы государственного аудита (факультет) МГУ имени М.В. Ломоносова.

Сайт устроен как атлас солнечной системы: в центре кафедра, девять орбит соответствуют масштабу объекта исследования (от единицы данных до космоса), каждая работа это тело на своей орбите. Карту можно перетаскивать и приближать; нажатие на тело или название орбиты открывает карточку справа. Кнопки внизу слева проигрывают историю: работы появляются на орбитах в год публикации. Вверху слева фильтры, сведения о проекте и поиск.

| № | Уровень | Что относится |
|---|---|---|
| 1 | Данные | единица информации, персональные данные |
| 2 | Алгоритм | программа, модель искусственного интеллекта |
| 3 | Человек | субъект права, пользователь, обучающийся |
| 4 | Организация | оператор, университет, информационная система |
| 5 | Отрасль | рынок, финансовая система, цифровая экономика |
| 6 | Государство | национальная правовая система, информационная безопасность России |
| 7 | Международный уровень | международная информационная безопасность, юрисдикция |
| 8 | Глобальная среда | глобальное информационное пространство, интернет, метавселенная |
| 9 | Космос | космическая деятельность, космонавтика, история космической техники |

Кроме орбит у работ есть темы (18 рубрик: ИИ, персональные данные, кибербезопасность, госаудит, космонавтика, история науки и др.; у работы может быть несколько тем). Тела можно раскрашивать по орбитам, темам, авторам или видам работ; у каждой темы своя карточка. Правила тем: `TOPICS` в `tools/build.py`.

Уровень присваивается автоматически по ключевым словам заглавия (правила `RULES` в `tools/build.py`); работы без признаков другого уровня попадают на уровень «Государство».

Сайт статический и без зависимостей: для просмотра достаточно открыть `index.html` в браузере.

## Структура

```
index.html          страница
assets/style.css    оформление в стиле атласа: чёрный фон, шрифт Jura, цветные орбиты
assets/img/         фотографии для галерей орбит (набор и подписи в data/research.js, PHOTOS)
assets/app.js       атлас на canvas: орбиты, тела, шкала времени, панель, поиск, фильтры
data/research.js    настройки: уровни, сотрудники, источники, работы вне ИСТИНА
data/works.js       работы из ИСТИНА МГУ (генерируется, вручную не править)
tools/build.py      сборка data/works.js из выгрузки
tools/istina/       выгрузка ИСТИНА: списки работ по профилям, BibTeX каждой записи, найденные DOI
```

## Обновление из ИСТИНА

1. Выгрузить заново списки (`tools/istina/<сотрудник>.txt`) и BibTeX (`bib.json`).
2. Запустить `python3 tools/build.py`: скрипт пересоберёт `data/works.js`, библиографические записи по ГОСТ Р 7.0.100-2018 и уровни шкалы.

## Как добавить работу вне ИСТИНА

Допишите объект в массив `WORKS` в `data/research.js` (поля: `id`, `authors`, `year`, `type`, `level`, `title`, `gost`, `source`, необязательно `verify`). Работы из ИСТИНА добавляются только пересборкой.

Стрельцова: система ИСТИНА МГУ, профили [1276994](https://istina.msu.ru/workers/1276994/), [3172534](https://istina.msu.ru/workers/3172534/), [26759990](https://istina.msu.ru/workers/26759990/), [2826393](https://istina.msu.ru/workers/2826393/);
* у каждой работы ссылка на её запись в ИСТИНА; DOI, Scopus, Web of Science и eLibrary там, где они указаны в ИСТИНА; для статей с 2015 года без DOI в ИСТИНА выполнен поиск в Crossref по заглавию и году (принимается совпадение заглавия не ниже 0,85 и год ±1);
* полные тексты: PDF с КиберЛенинки (поиск по заглавию, году и фамилии автора) и PDF открытого доступа по DOI (OpenAlex); у работ, к которым в ИСТИНА прикреплён файл, есть пометка (файл доступен после входа в ИСТИНА); данные в `tools/istina/fulltext.json`;
* доклад Д.Б. Фролова и мероприятие А.С. Зуевой и С.С. Калканова: программа конференции ВШГА МГУ (2023) и сайт ВШГА.
